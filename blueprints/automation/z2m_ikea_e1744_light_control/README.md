# IKEA E1744 조명 제어

Zigbee2MQTT에 연결된 IKEA SYMFONISK 1세대 회전 노브(E1744)로 조명의
밝기·색온도·색상·채도 중 하나를 조절한다. 한 번·두 번·세 번 클릭 동작은
자동화를 만들 때 직접 지정한다. MQTT 메시지를 직접 받으므로 action 센서나
상태 저장 도우미가 필요하지 않다.

[![Home Assistant에 블루프린트 가져오기](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fkkqq9320%2Fhomeassistant%2Fblob%2Fmain%2Fblueprints%2Fautomation%2Fz2m_ikea_e1744_light_control.yaml)

## 설치와 설정

1. Zigbee2MQTT에서 모델이 [E1744](https://www.zigbee2mqtt.io/devices/E1744.html)인지
   확인한다. SYMFONISK 2세대 버튼 리모컨과는 동작 구성이 다르다.
2. 위 버튼으로 블루프린트를 가져와 자동화를 만든다. 최소 HA 버전은
   [블루프린트](../z2m_ikea_e1744_light_control.yaml)의
   `blueprint.homeassistant.min_version`에 정의되어 있다.
3. **연결**에서 Z2M 기본 topic과 노브의 `friendly_name`을 입력한다.
   공백과 대소문자를 그대로 사용한다. 예를 들어 기본 topic이 `zigbee2mqtt`,
   노브 이름이 `ikea Knob`이면 `zigbee2mqtt/ikea Knob`의 JSON 메시지를 받는다.
   HA의 표시 이름이나 센서 ID를 입력하지 않는다.
4. 대상 조명과 **회전 기능** 하나를 선택한다. 여러 조명은 하나의 HA 조명 그룹으로
   지정한다. 그룹이 보고하는 집계 값을 기준으로 조절하므로 구성원별 밝기 차이는 유지하지 않는다.
5. **클릭 동작**에서 1·2·3회 클릭에 원하는 HA 동작을 지정한다. 기본값은 모두
   비어 있다. 빈 클릭도 진행 중인 회전은 멈춘다.
6. 같은 노브를 처리하는 기존 자동화를 끈 뒤 새 자동화를 사용한다. 동시에 켜면
   한 조작이 두 자동화에서 처리될 수 있다.

## 회전 기능

| 기능 | 오른쪽 회전 | 왼쪽 회전 | 조절 범위 |
|---|---|---|---|
| 조명 밝기 | 밝게 | 어둡게 | 1~100%, 회전으로 끄지 않음 |
| 조명 색온도 | 높은 K, 차갑게 | 낮은 K, 따뜻하게 | 조명이 보고한 Kelvin 지원 범위 |
| Light Hue — 색상 | 색상환 정방향 | 색상환 역방향 | 360° 순환, 채도 유지 |
| Light Saturation — 채도 | 선명하게 | 흰색에 가깝게 | 0~100%, 색상 유지 |

색온도·색상·채도 조절은 밝기를 변경하지 않는다. Hue는 채도가 0인 흰색 상태에서
돌려도 색이 드러나지 않는다. 이 경우 채도 조절로 선명도를 높일 수 있다.

대상 조명은 선택한 기능을 지원해야 한다. HA **개발자 도구 → 상태**에서 조명의
`supported_color_modes`를 확인한다. 색온도에는 `color_temp`, 색상·채도에는
`hs`, `xy`, `rgb`, `rgbw`, `rgbww` 중 하나가 필요하다. 색온도 전용 전구에는
색상·채도 명령을 보내지 않는다.

회전 기능은 자동화 설정에서 고정한다. 클릭으로 기능을 바꾸거나 누른 채 돌리는
별도 제스처를 해석하지 않는다.

## 꺼진 조명 켜기

밝기 기능에서는 **오른쪽 회전만** 조명을 켠다. 왼쪽 회전은 꺼진 상태를 유지한다.
**꺼진 조명을 켤 때 밝기 복원**으로 시작 방식을 선택한다.

- 끔: 0%를 계산 기준으로 시작한다. 밝기 변화량이 2%p이면 첫 명령부터 2%로 켠다.
  실제로 0% 명령을 보내거나, 복원 밝기로 먼저 켠 뒤 낮추지 않는다.
- 켬: 밝기를 지정하지 않고 조명을 켠다. 조명이 보고한 복원 밝기에서 다음 반복부터
  조절한다. 마지막 밝기 복원은 조명과 HA 통합의 켜기 동작을 따른다.

색온도·색상·채도는 양쪽 회전으로 켤 수 있다. 밝기 복원 설정과 관계없이 먼저
밝기를 지정하지 않고 켠 뒤, 복원 밝기를 유지하며 선택한 속성을 조절한다.

켜기 뒤에는 `on` 상태와 필요한 속성을 최대 2초 기다린다. 최대 반복 시간이
먼저 끝나거나 유효한 값이 보고되지 않으면 추가 명령 없이 종료한다.
회전 중 다른 동작으로 조명이 꺼지면 그 실행은 다시 켜지 않는다.

## 반응 속도와 중단

**조절량과 반복**에서 한 번에 바꾸는 양, 명령 처리 후 대기 간격, 최대 반복 시간을
조정한다. 입력 ID·기본값·선택 범위는 [블루프린트의 `input`](../z2m_ikea_e1744_light_control.yaml)에
정의되어 있다. 변화량은 물리적인 회전 한 칸이 아닌 반복 한 번에 적용된다.
Hue의 색상환 이동 비율 2%는 7.2°에 해당한다.

켜진 조명의 첫 조절은 즉시 실행하고, 이후에는 명령 처리가 끝난 뒤 설정 간격을
기다린다. 조명의 상태 보고가 늦어도 같은 실행에서는 직전 목표값에서 이어간다.
한계에 도달하면 같은 값을 계속 보내지 않는다.

정지·클릭·새 회전은 이전 실행의 남은 단계를 중단한다. 같은 방향의 시작 메시지가
다시 와도 새 실행이며, 그 시점의 조명 상태와 제한 시간으로 시작한다.
최대 반복 시간은 마지막 회전 시작 메시지 뒤에 적용된다.
이미 조명에 전달한 명령은 되돌리지 않는다.

새 조작은 대기 중인 사용자 클릭 동작도 중단한다. 클릭에서 별도 스크립트를
비동기로 실행했다면 그 스크립트는 자신의 실행 방식에 따른다.
HA 종료와 자동화 다시 불러오기도 진행 중인 실행을 멈춘다.

## 동작하지 않을 때

자동화 편집기의 수동 실행에는 MQTT `action` 정보가 전달되지 않는다.
클릭과 회전 동작은 노브를 조작하여 확인한다.

자동화의 실행 추적에서 종료 사유를 확인한다. 지원하지 않는 기능, 사용할 수 없는
조명 상태, 잘못된 속성, 켜짐 대기 시간 초과를 구분한다. 필요한 밝기·색온도·Hue가
없으면 임의의 값으로 바꾸지 않는다. 채도 누락·비수치 값에는 50을 사용하며,
숫자인 채도가 범위를 벗어나면 종료한다.
